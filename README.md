## 先说沪日 IX 到底是个什么东西

沪日 IX 是 Mkcloud 家的“上云互联优化专线”产品线，上海入口、日本 BGP 出口，官方给的端内参考延迟是 25~28ms。它和沪日 IPLC 直连款的主要区别不在速度，而在**入口的接入方式**：IX 的入口 IP 只在上海的互联网交换中心（IXP）内宣告，只有加入该交换中心的云厂网络能连进去——阿里云、腾讯云、百度云国内全网，以及火山云、华为云、UCloud 华东。三大运营商的普通家宽、普通公网 IP，连不上。

换句话说，沪日 IX 不是给“家里宽帶直连”准备的。它的目标用户是**业务已经跑在云服务器上的人**：比如店铺后台部署在腾讯云上海，再从云机连到这台专线 VPS，让对日本方向的访问走专线出去。

虎窝博客对这款 1TB IXP 套餐的测评解释得更直白：IX 入口因为只在交换中心内宣告，公网扫不到，天然避开一部分攻击面和被扫描的风险；同时 IX 带宽成本低于三大运营商的网络，所以同等流量额度下售价比直连入口便宜、流量给得更多。

这台 VPS 本身的规格是每台分配 **1 个独立入口 IP + 1 个独立出口 IP**，出口方向接的是日本 BGP（PCCWG、NTT、Cogent、Telstra 等多家运营商），并接入 Equinix IX、JPIX、JPNAP 等多个日本交换中心，对 Google、Cloudflare 有私有 PNI 连接。注意最后这条只是路径资源说明，官方明确不承诺所有目标都走私有直连。

## 最容易翻车的点：前置机

买 IX 之前必须先搞清楚前置机的事，不然开通了也白搭。

IX 产品不限连入省份，但前提是你的前置云机在支持范围内。上海入口支持的是阿里云、腾讯云、百度云国内全网，加上火山云、华东的华为云和 UCloud——具体以购物车说明为准，不是所有云厂、所有地域都行。家里那台 NAS、公司宽带、随便一台“大厂 BGP”机器，都不能代替云前置。

前置机本身也是要花钱的。虎窝那篇测评里，搭配的前置是腾讯云上海锐驰型，月费约 40 元；另一篇 2026 年的测评（catcat.blog）用的火山引擎 ECS 按量计费，机器加流量包折算下来并不便宜，作者还提到阿里云、腾讯云轻量实例标称 200M 带宽但存在被限速到 20M 甚至 1M 的实际案例。所以算总成本时要把**前置机租金 + 前置机流量 + 专线套餐**三项加在一起，只看 Mkcloud 的套餐单价会低估。

## 计费规则里容易误会的几件事

Mkcloud 的流量计费套餐有几个和普通 VPS 不一样的规则，下单前值得过一遍：

1. **双向计费**。1TB 指的是上行加下行的总和。每天上传 20GB、下载 10GB，一个月就是 900GB，不是 600GB。
2. **超量停机，不是限速**。超额后机器暂停，要么自助购买流量重置，要么工单补差价升级。早期预售时“超量限速 10Mbps”的规则已经是历史了，别拿旧规则做预期。
3. **共享带宽是峰值**。标称 200M 不保证持续跑满，短时突发场景看峰值，长跑场景应该去看独享款。
4. **升降级走工单**。降级到更便宜的套餐时差价不退；快照和备份不是产品自带能力，数据要自己备份。
5. **出口不收公网入站**。不能拿来建公开网站、收支付回调、做游戏服务端。它是给你“主动向外访问”用的。
